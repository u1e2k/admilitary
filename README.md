# AdMilitary (アドミリタリー)

**AdMilitary** は、Godot Engine 4 (GDScript) で開発された、Android携帯ゲーム機（物理ゲームパッド搭載デバイス）およびPC向けの「3Dローポリ・サイドアクション防衛プロトタイプ」です。

外部テクスチャを一切使わず、Godot標準のプリミティブメッシュと発光（Emission）マテリアルのみで軽量かつスタイリッシュなサイバーミリタリー世界観を構築しています。

---

## 🎮 操作方法 (Controls)

物理ゲームパッド（Anbernic / RGシリーズ / RGrotate 等）およびキーボード操作に完全対応しています。

| アクション | ゲームパッド | キーボード | 説明 |
| :--- | :--- | :--- | :--- |
| **左右移動** | 左スティック / 十字キー (左右) | `A` / `D` または `←` / `→` | 手前側で左右移動・間合い調整 |
| **射撃** | **全自動 (Auto Shoot)** | **全自動 (Auto Shoot)** | 奥方向の敵群へマシンガンを自動連射 |
| **決定 / スタート** | `A ボタン` (Cross) | `Space` / `Enter` | ゲーム開始・リトライ・カード決定 |
| **ポーズ** | `START` / `Options` | `ESC` / `P` | ゲームの一時停止 / 再開 |
| **カード選択** | 十字キー / スティック / `A,B,X` | `←,→` / `1,2,3` | レベルアップ時の強化カード選択 |

## 🌟 ゲームシステム

1. **タイトル＆スタート画面 (`Main.gd`)**:
   - 起動時はタイトル画面が表示され、`A ボタン` または `Space` で戦闘開始。
2. **小隊システム & 感度最適化 (`Player.gd`)**:
   - スムーズかつ制御しやすいマイルドな移動感度に調整。
   - 兵士数が増加すると横並び・後方に隊列を組み、奥（-Z方向）に向かって一斉弾幕を掃射。
3. **EXP & ローグライク・レベルアップシステム**:
   - 敵を撃破するとEXP（経験値）を獲得。ゲージが満タンになるとレベルアップ！
   - ゲームが一時停止し、3枚の強化カード（兵士増員、連射速度UP、威力UP、オーバードライブ等）から好みのビルドを選択可能。
4. **倍率・強化ゲート (`Gate.gd`)**:
   - 奥から迫るネオンフレームゲートを通過することで即座にパワーアップ。
5. **ポーズ機能**:
   - いつでも `START` ボタンまたは `ESC` で一時停止可能。
6. **敵ウェーブ & 巨大怪獣ボス (`Enemy.gd` / `Boss.gd`)**:
   - **Wave 1〜3**: 画面奥から赤色ゾンビ群が手前に前進。
   - **Wave 4 (Final Wave)**: 画面奥から巨大な黒×赤発光の「GIGA KAIJU」が出現。
7. **防衛ライン & リザルト (`Main.gd`)**:
   - プレイヤー背後（手前側 Z = 10）の「DEFENSE LINE」を敵に突破されるとゲームオーバー。
   - ボスを撃破するとミッションコンプリート。

## 📁 プロジェクト構成

```
.
├── project.godot                     # プロジェクト設定（720x1280 Portrait, Mobileレンダラー, 入力マップ）
├── scenes/
│   ├── Main.tscn                     # メインステージ・クォータービューカメラ・ライティング・UI
│   ├── Player.tscn                   # プレイヤー小隊の基底シーン
│   ├── Bullet.tscn                   # 高速シアン弾丸 (Area3D)
│   ├── Gate.tscn                     # 強化ゲート（発光フレーム + Label3D）
│   ├── Enemy.tscn                    # 赤色ゾンビ (CharacterBody3D)
│   └── Boss.tscn                     # 巨大怪獣ボス (CharacterBody3D)
└── scripts/
    ├── Main.gd                       # ステージ自動生成・ウェーブ進行・スポーン管理
    ├── Player.gd                     # ゲームパッド対応左右移動・小隊増殖・オート連射
    ├── Bullet.gd                     # 直進・当たり判定・ノックバック付与
    ├── Gate.gd                       # 強化ゲートロジック
    ├── Enemy.gd                      # ゾンビ挙動・被弾点滅・ブロック飛散消滅
    ├── Boss.gd                       # ボス挙動・咆哮アニメーション・大爆発消滅
    └── ParticleHelper.gd             # 動的キューブ飛散エフェクト生成ヘルパー
```

## 🚀 実行・ビルド手順

### PCでの実行
1. Godot 4.x（4.2 / 4.3 推奨）を起動します。
2. 本プロジェクトフォルダを選択してインポートし、プロジェクトを開きます。
3. `F5` キー（または右上の再生ボタン）を押すと即座にゲームが開始します。

### Android携帯ゲーム機 (RGrotate / APK) へのエクスポート
1. Godotエディタのメニューから **「プロジェクト (Project)」 → 「エクスポート (Export)」** を開きます。
2. **「追加 (Add)」 → 「Android」** を選択します。
3. Android SDK / キーストアの設定を確認後、**「プロジェクトのエクスポート (Export Project)」** を実行して `.apk` ファイルを出力します。
4. 生成された APK をデバイスに転送してインストール、または ADB 経由で直接インストールします：
   ```bash
   adb install -r AdMilitary.apk
   ```

## ⚡ パフォーマンス・設計仕様
- **Renderer**: `Mobile`（または `Compatibility`）推奨。
- **Asset-Free**: 画像テクスチャを一切使用せず、Godot標準のBox/Capsule/CylinderメッシュとEmissionマテリアルのみで完結。
- **Collision Optimization**: 弾丸に軽量な `Area3D`、敵にはシンプルなレイヤー分離（Player, Enemy, Bullet, Gate）を適用し、数十体以上の敵が出現しても低スペック携帯機で60fpsを維持します。
